# Leaf Species Detection

Predicts iris species (setosa, versicolor, virginica) from four flower measurements using a Decision Tree classifier.

## Tools
Python, pandas, NumPy, matplotlib, scikit-learn

## What I did
- Explored the Iris dataset (150 flowers, 4 features)
- Split the data into training and test sets
- Trained a Decision Tree and measured its accuracy
- Tested how tree depth affects performance

## Files
- `01_leaf_species_detection.ipynb`: the full notebook

## Dataset
The classic Iris dataset (150 samples, 4 features, 3 species). The dataset file is not included in this repository.

## How to run
Install the libraries:

    pip install pandas numpy matplotlib scikit-learn

Then open the notebook in Jupyter and run all cells.
